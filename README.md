# Topacut

A clean Android project scaffold with a GitHub Actions build.

## Build

Push to `main` or run the workflow manually from GitHub Actions.

The workflow uses Android Gradle Plugin 9.4.0 with Gradle 9.6.0 and JDK 17.

The generated debug APK is uploaded as a workflow artifact named `topacut-debug-apk`.

## Important

This repository contains only a clean starter project. It does not include decompiled or redistributed third-party app code.
